# PDF Image Extractor v1.1.0 リリースノート

PDFファイルから埋め込み画像を元の画質・透過情報を維持したまま一括抽出するデスクトップツール **PDF Image Extractor v1.1.0** をリリースしました。  
本バージョンでは、Windows向け公式インストーラーの提供開始、アプリ内からの自動アップデート機能、抽出進捗のプログレスバー表示と即時中断機能の追加など、大幅なユーザー体験の向上と信頼性の強化を実施しました。

---

## 🌟 主なハイライト

1. **Windows向け公式インストーラー（Setup.exe）の提供開始**:
   - スタートメニュー登録、デスクトップショートカット作成、標準アンインストーラーを備えたインストーラーを提供開始しました。
   - 一般ユーザー権限および管理者権限の両方に対応しており、環境を選ばず安全にインストール可能です。
2. **GitHub Releases 連携による自動アップデート機能**:
   - アプリのメニューバーから「ヘルプ」→「アップデートを確認...」を選択することで、最新バージョンの自動検知・ダウンロード・ハッシュ検証・置換起動をワンストップで行えるようになりました。
3. **プログレスバー表示と即時キャンセル対応**:
   - 画像抽出の進捗状況をプログレスバーと進捗率（%）でリアルタイムに可視化。
   - 処理中に「中断」ボタンを押すことで、PDF処理を安全かつ即座にキャンセルできるようになりました。
4. **自動ビルド＆チェックサム検証基盤の整備**:
   - `build.py` によるワンコマンドでの単体 exe ビルド、Inno Setup インストーラー作成、および SHA-256 チェックサム自動生成を整備しました。
5. **テスト駆動による品質向上**:
   - 120件を超える自動テスト（pytest）を導入し、抽出ロジック、設定管理、GUI連携、自動更新の堅牢性を担保しています。

## 🔒 チェックサムの照合手順 (PowerShell)

ダウンロードしたファイルの完全性を確認するには、PowerShell で以下のコマンドを実行してください。

```powershell
# インストーラー版の検証
Get-FileHash .\PDFImageExtractor_Setup_v1.1.0.exe -Algorithm SHA256
Get-Content .\PDFImageExtractor_Setup_v1.1.0.exe.sha256

# ポータブル版の検証
Get-FileHash .\PDFImageExtractor.exe -Algorithm SHA256
Get-Content .\PDFImageExtractor.exe.sha256
```

出力された `Hash` の値が、`.sha256` ファイル内のハッシュ値と一致していれば正常です。

## 📝 変更履歴・詳細

### 新機能
- **Inno Setup インストーラー作成基盤**:
  - `installer.iss` を新規作成し、日本語・英語対応、ショートカット登録、アンインストーラーを整備。
  - `build.py` に `--installer` および `--skip-pyinstaller` オプションを追加。
- **自動アップデート機構 (`updater.py`)**:
  - GitHub REST API を用いた最新リリース情報の取得。
  - セマンティックバージョニングに基づくバージョン比較。
  - SHA-256 ハッシュ照合付きバイナリダウンロードと安全なプロセス切り替え起動。
- **進捗通知とキャンセル制御**:
  - `extractor.py` に `cancellation_token` および `progress_callback` を追加。
  - GUI 上での進捗率・ステータス表示および中断ボタンの連動。

### 改善・リファクタリング
- **設定ファイル管理の堅牢化 (`config_manager.py`)**:
  - アプリ同階層への書き込み権限がない場合、自動的に `%APPDATA%\pdf-image-extractor` 配下へフォールバック保存。
  - 不正な JSON データや壊れた履歴の自動復旧機構を追加。
- **ビルドサイズの最適化**:
  - PyInstaller の除外設定を見直し、不要な外部ライブラリの同梱を防ぐことでバイナリサイズを大幅削減。
- **ドキュメントの充実**:
  - 実行ファイル作成ガイド、仮想環境利用ガイド、README の大幅改定。
