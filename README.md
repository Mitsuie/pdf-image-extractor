# PDF掲載画像抽出ツール (PDF Image Extractor)

PyMuPDF（`fitz`）ライブラリを使用した、PDFファイルから埋め込み画像を抽出するデスクトップアプリケーションです。直感的なGUI（Tkinterベース）で、簡単な操作で単一または複数のPDFファイルから画像を元の品質・透過情報を維持したまま一括で抽出できます。

---

## 主な特徴

1. **TkinterベースのGUI**:
   - `ttk` (Clamテーマ) を使用したデスクトップインターフェース。
   - 「単一PDFファイルから抽出」と「フォルダ内PDFから一括抽出」をラジオボタンで切り替え可能。
2. **保存先フォルダの履歴管理**:
   - 過去に指定した保存先フォルダの履歴を最大3件まで保存し、コンボボックスから選択・再利用可能。
   - 実行ファイルやスクリプトと同一フォルダに設定ファイル `config.json` を保存（書き込み権限がない場合は自動的に `%APPDATA%\pdf-image-extractor` 配下へフォールバック）。
3. **抽出完了後のフォルダ自動オープン**:
   - 「抽出完了後に保存先フォルダを開く」チェックボックスがオンの場合、抽出完了時に保存先フォルダをエクスプローラーで自動的に開く。
4. **透過（アルファチャンネル）情報の復元**:
   - PDF内で分離して保存されている透過情報（透過マスク）とベース画像を自動的に再結合し、透過状態を維持したPNG形式として出力。
5. **PDF別フォルダへの自動整理保存**:
   - 指定した保存先フォルダの中に、PDFファイル名と同名のサブフォルダを自動生成し、PDFごとに整理して保存。
6. **キャプション解析と物理座標によるソート**:
   - PDF内のテキストから `図1-2`、`Fig. 3`、`画像 5` などのキャプション情報を正規表現で検出し、図番号順に画像をソートして抽出。
   - キャプションが検出されなかった画像については、ページ上の物理配置（Y座標：上から下、X座標：左から右）に基づいてソートし、図番号順の画像の後ろに結合。
7. **図番号に対応したファイル命名**:
   - キャプションから図番号が検出された画像は、ファイル名に `_fig[図番号]` (例: `[PDF名]_page1_fig1-2.png`) を自動付与。
   - キャプションがない画像は画像連番（例: `[PDF名]_page1_3.png`）で保存。
8. **マルチスレッドによるバックグラウンド処理**:
   - 画像抽出処理を別スレッドで実行するため、処理中もGUIの操作がフリーズせず、リアルタイムに進捗ログを表示可能。
9. **抽出進捗のプログレスバー表示と即時中断**:
   - 抽出処理の進捗率（%）とプログレスバーをリアルタイムに更新表示。
   - 大量ページや大容量PDFの処理中でも、「中断」ボタンにより即座かつ安全に抽出をキャンセル可能。
10. **GitHub Releases 連携による自動アップデート**:
    - メニューバーの「ヘルプ」→「アップデートを確認...」から、最新リリースの有無をワンクリックで確認。
    - 新バージョンが見つかった場合、SHA-256 チェックサムの照合を伴う自動ダウンロードとシームレスな更新起動が可能。
11. **処理中の終了確認機能**:
    - 画像の抽出処理が実行されている最中にウィンドウを閉じようとした場合、確認ダイアログを表示して安全に確認。

## 起動・実行方法

本アプリケーションは、**「① インストーラー（推奨）」**、**「② ポータブル版実行ファイル（.exe）」**、および **「③ Pythonスクリプトから直接実行」**の3つの方法で利用可能です。

### 方法①：インストーラーによるインストール（推奨）

一般利用に最も推奨される方法です。

1. GitHub Releases または `dists/` フォルダ内の `PDFImageExtractor_Setup_v1.1.0.exe` をダブルクリックして起動します。
2. 画面の指示に従ってインストールを進めます（スタートメニューへの追加やデスクトップショートカットの作成が選択可能です）。
3. インストール完了後、スタートメニューやデスクトップからすぐにアプリを起動できます。アンインストールも「設定」→「アプリ」から簡単に行えます。

---

### 方法②：環境構築不要！ポータブル版（.exe）での実行

USBメモリ等から持ち歩いて使いたい場合や、インストールを行わずに単体ファイルで使用したい場合に最適です。

1. `dists/` フォルダ内の `PDFImageExtractor.exe` をダブルクリックします。
2. 数秒でGUI画面（デスクトップアプリ）が立ち上がります。

> [!NOTE]
> 実行ファイル（`.exe`）およびインストーラーの動作仕様、セキュリティ警告（SmartScreen）への対処法などの詳細については、[executable_creation_guide.md](doc/executable_creation_guide.md) を参照してください。

---

### 方法③：Pythonスクリプトから直接実行する方法（開発・デバッグ用）

#### 1. 依存ライブラリのインストール
PowerShellまたはコマンドプロンプトを起動し、本プロジェクトのフォルダ内で以下のコマンドを実行して、必要なライブラリをインストールします。

```powershell
pip install -r requirements.txt
```

> [!TIP]
> 開発環境を汚さないために、Python仮想環境（`venv`）を構築した上でインストール・実行することを推奨します。仮想環境の作成やアクティベート手順の詳細は、[venv_guide.md](doc/venv_guide.md) を参照してください。

#### 2. アプリケーションの起動
以下のコマンドを実行します。

```powershell
python main.py
```

## 操作手順

1. **処理モードの選択**:
   - 「単一のPDFファイルから抽出」または「フォルダ内のすべてのPDFファイルから一括抽出」のいずれかを選択します。選択に合わせて、入力欄が自動的に有効・無効化されます。
2. **入力元・保存先の設定**:
   - **単一ファイルの場合**: 「ファイル選択...」ボタンから対象のPDFファイルを選択します。
   - **フォルダ一括の場合**: 「フォルダ選択...」ボタンからPDFファイルが格納されているフォルダを選択します。
   - **保存先**: 画像を保存したい出力先フォルダを指定します（履歴がある場合はドロップダウンリストから選択可能です）。
   - **自動オープン**: 抽出完了後に保存先フォルダをエクスプローラーで自動的に開きたい場合は、「抽出完了後に保存先フォルダを開く」にチェックを入れます。
3. **実行と進捗**:
   - グリーン色の「画像抽出を実行」ボタンをクリックすると、抽出が開始されます。
   - プログレスバーに進捗状況が表示され、下部の「処理ログ」エリアに詳細ログがリアルタイム表示されます。
   - 処理を途中でやめたい場合は、イエロー色の「中断」ボタンを押すことで即座に抽出をキャンセルできます。
4. **自動アップデート**:
   - メニューバーの「ヘルプ」→「アップデートを確認...」から、いつでも最新バージョンへの更新を確認・適用できます。
5. **終了**:
   - アプリを閉じる際は、レッド色の「終了」ボタンまたはウィンドウの閉じるボタン（×）をクリックして安全に終了できます。
