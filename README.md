# PDF掲載画像抽出ツール (PDF Image Extractor)

PyMuPDF（`fitz`）ライブラリを使用した、PDFファイルから埋め込み画像を抽出するデスクトップアプリケーションです。直感的なGUI（Tkinterベース）で、簡単な操作で単一または複数のPDFファイルから画像を元の品質・透過情報を維持したまま一括で抽出できます。

---

## 主な特徴

1. **直感的で洗練されたGUI**:
   - `ttk` (Clamテーマ) を採用したモダンなインターフェース。
   - 分かりやすいカラー設計（抽出ボタンは**洗練されたグリーン `#2a9d8f`**、終了ボタンは**警告を示す落ち着いたレッド `#e76f51`**）。
   - 「単一PDFファイルから抽出」と「フォルダ内PDFから一括抽出」をラジオボタンで簡単に切り替え可能。
2. **透過（アルファチャンネル）情報の復元**:
   - PDF内で分離して保存されている透過情報（透過マスク）とベース画像を自動的に再結合します。
   - 透過画像は透過状態を完全に維持したままで **PNG形式** として出力されます。
3. **PDF別フォルダへの自動整理保存**:
   - 指定した保存先フォルダの中に、**PDFファイル名と同名のサブフォルダ**が自動生成されます。
   - 抽出画像はPDF名ごとのフォルダに整理保存されます。
4. **キャプション解析と物理座標のハイブリッド自動ソート**:
   - PDF内のテキストから `図1-2`、`Fig. 3`、`画像 5` などのキャプション情報を高度な正規表現で自動検出し、**図番号順**に画像をソートして抽出します。
   - キャプションが紐付かなかった画像については、自動的に**ページ上の物理配置（Y座標：上から下、X座標：左から右）**に基づいてソートされ、図番号順の画像の後ろへ綺麗に補完・結合されます。
5. **図番号によるファイル命名の連動**:
   - キャプションから図番号が検出された画像は、ファイル名に自動的に `_fig[図番号]` (例: `[PDF名]_page1_fig1-2.png`) が付与されます。これにより、PDF本文の記述と抽出された画像を直感的に一瞬で対応付けることができます。
   - キャプションが無いものは従来通り `_[画像連番]`（例: `[PDF名]_page1_3.png`）で保存されます。
6. **マルチスレッドによる快適な操作性**:
   - 画像抽出の重い処理をバックグラウンドスレッドで処理するため、大量 of PDFを処理する際にも**画面がフリーズ（応答なし）せず**、リアルタイムに進捗ログを確認できます。
7. **安全装置付き「終了」ボタン**:
   - ボタンの隣に終了ボタンを均等配置。
   - 万が一、画像の抽出処理が走っている最中に終了ボタンを押してしまった場合は、強制終了を確認する警告ダイアログを表示する安全設計です。

## 実行方法

本アプリケーションは、**「① ビルド済み実行ファイル（.exe）を使用する方法」**と、**「② Pythonスクリプトから直接実行する方法」**の2つの方法で利用可能です。

---

### 方法①：環境構築不要！ビルド済み実行ファイル（.exe）での実行

`dists/app.exe` を使用すると、Python環境や追加のライブラリインストールを一切行うことなく、すぐにアプリケーションを実行できます。

#### 💡 `dists/app.exe` の活用方法とメリット
* **完全スタンドアロン動作**: 
  実行に必要なPython本体や `PyMuPDF` ライブラリ一式がすべて1つのファイルに内包されているため、**Pythonがインストールされていない他のWindows PC**でもダブルクリックするだけでそのまま動作します。
* **ポータブル性**: 
  `app.exe` ファイル単体をUSBメモリなどで持ち運んだり、他のメンバーへ配布してそのまま画像抽出ツールとして使ってもらうことが可能です。
* **実行手順**:
  1. `dists/` フォルダ内の `app.exe` をダブルクリックします。
  2. 数秒でGUI画面（デスクトップアプリ）が立ち上がります。

*(※ 開発者向け: `app.exe` を再ビルドしたい場合は、仮想環境下で `pyinstaller --onefile --noconsole app.py` を実行して生成された `dist/app.exe` を `dists/app.exe` に配置してください。)*

---

### 方法②：Pythonスクリプトから直接実行する方法（開発・デバッグ用）

#### 1. 依存ライブラリのインストール
PowerShellまたはコマンドプロンプトを起動し、本プロジェクトのフォルダ内で以下のコマンドを実行して仮想環境を作成・有効化し、必要なライブラリをインストールします。

```powershell
# プロジェクトフォルダへ移動
cd "d:\Google Drive\マイドライブ\43_プログラム開発\pdf-image-extractor"

# 仮想環境（.venv）を作成
python -m venv .venv

# 仮想環境を有効化（PowerShell）
.venv\Scripts\Activate.ps1
# もしくは（コマンドプロンプト）
.venv\Scripts\activate.bat

# 依存ライブラリ（PyMuPDF、PyInstaller等）をインストール
pip install -r requirements.txt
```

#### 2. アプリケーションの起動
仮想環境が有効な状態で、以下のコマンドを実行します。

```powershell
python app.py
```

## 操作・動作確認の手順

1. **処理モードの選択**:
   - 「単一のPDFファイルから抽出」または「フォルダ内のすべてのPDFファイルから一括抽出」のいずれかを選択します。選択に合わせて、入力欄が自動的に有効・無効化されます。
2. **入力元・保存先の設定**:
   - **単一ファイルの場合**: 「ファイル選択...」ボタンから対象のPDFファイルを選択します。
   - **フォルダ一括の場合**: 「フォルダ選択...」ボタンからPDFファイルが格納されているフォルダを選択します。
   - **保存先**: 画像を保存したい出力先フォルダを指定します（自動的にその中にPDF名フォルダが作成されます）。
3. **実行**:
   - グリーン色の「画像抽出を実行」ボタンをクリックすると、抽出が開始されます。
   - 抽出される画像は自動的に**キャプション解析（図番号順）および物理的な描画位置（上から下、左から右）**に高度にソートされ、ファイル名に図番号（`_fig[図番号]`）が自動マッピングされて保存されます。
   - 進捗や処理結果は下部の「処理ログ」エリアにリアルタイムで表示されます。
4. **終了**:
   - アプリを閉じる際は、レッド色の「終了」ボタンをクリックして安全にプログラムを終了できます。
